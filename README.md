# SALES DASHBOARD OF YEAR 2020-22 | Power BI Project

An interactive and professional sales analysis dashboard built in Power BI to track business performance from 2020 to 2022.

### 📸 Dashboard Preview
[Sales Dashboard](powerbi_dashboard.png)

### 📂 Files in this Repository
1.  **Complete_Techno_Sales_Data-2.xlsx** - Raw dataset used for analysis
2.  **PowerBI_Sales_dashboard_2020-22.pbix** - Main Power BI file (with DAX & Data Modeling)
3.  **powerbi_dashboard.png** - High-resolution screenshot of dashboard

### 📊 Key Insights / KPIs Shown
- **Total Sales:** 99M
- **Total Cost:** 76M
- **Total Quantity Sold:** 13K
- **Total Transactions:** 5K
- **Total Profit:** 23M

### 📈 Visuals Used
- **Bar Chart:** Quantity by Category wise
- **Map Visual:** Sum of Sales by State
- **Pie Chart:** Total Sales by Brand
- **KPI Cards:** For Total Sales, Cost, Quantity
- **Slicers:** Top Sales Persons Filter

### 🛠️ Tools & Concepts Used
- Power BI Desktop
- Power Query (Data Cleaning & Transformation)
- DAX (Measures for Sales, Cost, Profit)
- Data Modeling

### 🚀 How to Run This Project
1. Download all files
2. Open `PowerBI_Sales_dashboard_2020-22.pbix` in Power BI Desktop
3. If data source error comes, go to `Transform Data > Data Source Settings` and link Complete_Techno_Sales_Data-2.xlsx`
